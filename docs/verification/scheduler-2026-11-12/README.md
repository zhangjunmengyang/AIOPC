# 本地定时任务实测

2026-11-12，在 macOS 上由 launchd 按分钟计划启动独立 OpenCode CLI，读取模拟订单与价格数据，生成报告和提醒文件。任务来源为 `scheduled`，两次运行均退出成功：11:29:05 开始，耗时 30.281 秒；最终版本 11:41:05 开始，耗时 29.207 秒。临时任务、launchd 配置和测试锁已删除。

| 验证 | 结果与证据 |
| --- | --- |
| 计划触发、模型执行、文件写入 | [最终运行记录](final-scheduled-run.json)、[进程结果](final-runs.jsonl)、[生成的报告](final-report.md) |
| 数据汇总、价格变化、提醒 | 使用 [模拟数据](metrics.json)：收入合计 20，价格由 9 到 12、变化 3；提醒保存为 Markdown |

| 对话中的立即运行 | MCP `run_job` 连续调用两次，同样只启动一次，并回写超时状态。见 [MCP 结果](mcp-run.json) |
| 桌面回归 | 桌面 Node 测试、Electron TypeScript 检查和 bridge 检查通过；新增 scheduler 测试共 5 项通过 |

安装流程把固定版本 `opencode-scheduler@1.3.0` 包装成本地 MCP，供两种引擎调用。系统任务使用 `~/.aiopc/bin/aiopc-scheduled`，每个项目有独立数据库与持久配置；不连接桌面服务，因此执行不依赖桌面窗口。测试时没有关闭用户正在使用的应用。

原插件的超时信号处理器在等待子进程前就失效，实测会留下运行状态和锁。[修复前结果](reliability-before-fix.json) 保留了失败记录。安装副本修正该处理器，并使用 AIOPC 私有 supervisor，避免其他项目的旧插件覆盖。MCP 的立即运行也经过同一个 supervisor。

后台任务默认允许读取、检索、网页读取和项目内写入，禁止登录、填发布页、发布、发信、交互提问和会话共享。可在对话中创建、查看、修改、删除任务与读取日志；提醒目前是项目文件，尚未接系统通知。实测使用模拟数据，没有对外发送、发布，也没有验证真实平台的数据拉取。macOS 已验证；Linux 尚未实测，Windows 暂不注入该 MCP。
