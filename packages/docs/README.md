# AIOPC 使用指南

AIOPC 是给一人公司用的 AI 桌面工作台：从一个想法出发，把产品、品牌、营销、获客和复盘串成一条能持续推进的工作线。你和 AI 在对话里推进工作，产物都以文件落在项目里，对外动作（发帖、互动）由你确认。

## 页面一览

| 位置 | 做什么 |
| --- | --- |
| 新建任务 | 和 AI 开始一段对话，所有工作都从这里推进 |
| 资料空间 | 当前项目的文档、图片、视频、知识库和稿件 |
| 账号 | 连接社交平台账号，管理每个账号的连接方式和发布记录 |
| 连接 | 技能、MCP 服务、插件等给 AI 增加能力的扩展 |
| 左侧「项目」 | 每个项目是一个工作区文件夹，切换项目就是切换工作区 |
| 设置 | 模型服务商、外观、权限等 |
