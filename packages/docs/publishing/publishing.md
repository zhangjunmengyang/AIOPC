# 发布内容

1. 和 AI 聊清楚要写什么。AI 先写原稿（`content/<日期>-<主题>/draft.md`），再按平台改写成各平台稿件，需要时生成配图。
2. 在对话或资料空间里查看、修改稿件；文件可以直接编辑，AI 会保留你的修改。
3. 确认后让 AI 发布。每次发布前 AIOPC 都会请你在对话里批准。
4. 结果有两种：
   - **已填好发布页**：在右侧内置浏览器里检查后由你点发布。发布后把链接告诉 AI，它会记录到项目。
   - **已发布**：账号接了官方接口，已直接发出，链接自动记录。
5. 发布记录在账号页下方和项目的 `social/log.jsonl`；之后可以让 AI 读回帖子数据和评论来复盘。

回复评论、去别人话题下互动同样会先给你看内容，确认后再执行。
