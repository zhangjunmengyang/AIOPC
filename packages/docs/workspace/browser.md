# 内置浏览器

AIOPC 自带浏览器，用来看网页、点链接。账号登录和 AI 的平台操作都在[项目环境](environment.md)里进行；没有容器引擎、也没配置云端浏览器时，才退回到内置浏览器。

- 对话或页面需要打开网页时，浏览器出现在右侧；拖动中间的分隔条调整宽度。
- 「完整视图」让浏览器铺满 AIOPC 窗口，按 Esc 或点「退出完整视图」回到侧边栏；也可以在独立窗口打开。
- 桌面网页宽于面板时会自动缩小以完整显示。
- 内置浏览器无法安装插件；需要密码管理器等插件时，在项目环境的画面里从 Chrome 应用商店安装。
