# 内置浏览器

AIOPC 自带浏览器，平台登录和 AI 的网页操作都在这里进行，不会打扰你自己的 Chrome。

- 对话或页面需要打开网页时，浏览器出现在右侧；拖动中间的分隔条调整宽度。
- 「完整视图」让浏览器铺满 AIOPC 窗口，按 Esc 或点「退出完整视图」回到侧边栏；也可以在独立窗口打开。
- 桌面网页宽于面板时会自动缩小以完整显示。
- 登录状态在所有项目间共用。浏览器插件（例如密码管理器）无法安装；可以用 1Password 的通用自动填充（在登录框按 ⌘\）。
