# 项目环境

每个项目都有一台自己的电脑，跑着真实的 Chrome 内核浏览器。AI 在里面登录账号、填发布页、读数据，不占用你的浏览器，也不会弹窗打扰你。

一个项目一个环境，登录状态只留在这个项目里。换一个产品、换一批账号时，不会和别的项目串号。

## 在哪里运行

在「账号」页顶部的「项目环境」里可以看到它在哪儿运行、是否已启动，点右边的设置按钮可以更换。

| 方式 | 说明 |
| --- | --- |
| 本机沙箱（默认） | 在这台电脑上用容器跑，免费，数据不出本机。需要 OrbStack 或 Docker Desktop；没装的话 AIOPC 可以帮你装。 |
| Kernel | 云端浏览器，按项目保存登录状态，每月有免费额度。 |
| Browserbase | 被最多工具集成的云端浏览器，需要 API Key 和 Project ID。 |
| Steel | 开源的云端浏览器，也可以填自己部署的地址。 |
| Hyperbrowser | 云端浏览器，profile 保存登录状态。 |
| Anchor Browser | 云端浏览器，按名字保存 profile。 |
| Browser Use Cloud | 单价最低的云端浏览器。 |
| 自定义 | 任何支持 Chrome DevTools 协议（CDP）的环境，填它的地址即可。 |

已经在某家充了值，填上 API Key 就能用，密钥只保存在 macOS 钥匙串里。

## 登录状态迁移

项目第一次启动环境时，AIOPC 会自动把内置浏览器里已经登录的账号搬过去，不用重新扫码。之后想再搬一次，在环境设置里点「搬运登录状态」。

## 登录新账号

在「账号」页点「连接账号」并选平台，会跳到对话里由 AI 带你登录：

- 要扫码的平台，AI 把二维码单独发给你，用手机 App 扫一下即可。
- 用手机号登录的平台，AI 问你手机号，帮你点「获取验证码」，再问你收到的验证码。
- 少数拒绝自动化的网站（例如谷歌账号），AI 会请你打开右侧的「项目环境」画面亲自操作一下。

## 看画面与接管

平时不用看它。想看 AI 在做什么，或者需要你亲自操作时：

- 在对话右侧面板选「项目环境」，画面就在聊天旁边；
- 或在「账号」页点「看画面」，铺满 AIOPC 窗口。

在画面里可以直接用鼠标和键盘操作，也能打开 Chrome 应用商店装插件（例如 1Password，在插件里登录后就能自动填充）。
