# 常见问题

**资料空间或账号页显示「业务服务正在启动」很久**
第一次启动会为业务服务安装 Python 组件，可能需要一分钟。若一直不可用，重启 AIOPC；仍不行时查看 `~/.aiopc` 是否可写。

**连接账号时检测不到登录**
先在右侧内置浏览器里完成登录（扫码或密码），再点「我已登录」。小红书、X、抖音、B 站、TikTok、知乎能识别出具体账号；其他平台会直接保存当前浏览器的登录。

**网页在侧边栏里显示不全**
内置浏览器会把放不下的桌面网页自动缩小到适合面板的宽度；也可以拖宽侧边栏，或点「完整视图」让浏览器铺满窗口（按 Esc 返回）。

**AI 说某个工具未配置**
- 生图、视频：在 `~/.aiopc/.env` 和 `~/.aiopc/media-profiles.json` 里配置接口后重启 AIOPC。
- X 第三方数据：在「账号 → X 账号 → 连接方式」里填写 twitterapi.io 的 API Key。
