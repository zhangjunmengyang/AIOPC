# 账号与连接方式

账号的登录状态留在项目自己的[环境](../workspace/environment.md)里，不同项目互不串号。在左侧「账号」页点「连接账号」，按国内、出海选平台，AI 会在对话里带你登录。

## 连接方式

每个平台都可以用**浏览器登录**：在项目环境里登录一次（AI 把二维码发给你扫，或问你手机号和验证码），登录状态会保存，AI 之后在网页上帮你操作；能自动填写发布页的平台（小红书、公众号、知乎、微博、抖音、B 站、X 等）可以直接让 AI 填好发布页。

部分平台还有其他方式，连接时可选，之后也能在账号详情里添加：

| 平台 | 其他方式 | 能做什么 |
| --- | --- | --- |
| X | X 官方接口（4 个密钥） | 你在对话里批准后直接发布纯文字帖子 |
| X | X 第三方数据（twitterapi.io） | 搜索、竞品主页、回复与提及、帖子数据；按条计费、本地缓存 |
| Bluesky | Bluesky 官方接口（应用专用密码） | 直接发帖（最多 4 张图），读回帖子、数据与通知 |
| GitHub | GitHub 官方授权 | AIOPC 自动安装 GitHub 命令行并打开授权页，确认后 AI 能处理仓库、Issue、PR、通知 |

AIOPC 会为每件事自动选最合适的方式：发布时优先官方接口，读取时依次用官方接口、第三方数据、浏览器。某种方式做不了的事（例如官方接口暂不支持带图）会自动退到下一种。

密钥只保存在 macOS 钥匙串，不写进文件，也不会出现在对话里。

## 账号详情

点账号进入详情：查看和管理各连接方式（检查登录、重新登录、启用或移除官方接口、配置第三方数据），修改显示名称，或移除账号。账号页下方是当前项目的最近发布记录。
