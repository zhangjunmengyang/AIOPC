# 项目与资料空间

## 工作区就是项目

每个工作区是一个项目——一个产品，或公司本身。左侧「项目」列表里切换工作区，就是切换项目；AI 的工作目录就是当前项目文件夹。新建项目：点「项目」旁的 +，选一个文件夹。

项目的记忆都在文件里：

| 文件 | 内容 |
| --- | --- |
| `CONTEXT.md` | 产品事实与来源：用户、问题、阶段、已知事实、待验证假设 |
| `brand.md` | 品牌：名称、一句话介绍、语气、视觉、不说的话 |
| `marketing-plan.md` | 营销计划与复盘结论 |
| `decisions.md` | 关键决定 |
| `MEMORY.md` | 最近进展，AI 每次收工更新 |
| `knowledge/` | 资料：竞品、用户反馈、调研、数据 |
| `assets/` | 素材；AI 生成的图片和视频在 `assets/generated/` |
| `content/` | 稿件：每篇一个目录，原稿 `draft.md`，各平台稿 `xhs.md`、`wechat.md` 等 |
| `accounts/` | 某个账号在这个项目里的人设与口吻 |
| `social/log.jsonl` | 发布记录 |

AI 开工前读这些文件（`get_project_brief`），收工时把新事实和产物写回去；还没有这些文件时，让 AI 帮你「整理成项目记忆」即可建好。

## 共用的东西

社交账号和方法库所有项目共用；需要别的项目的资料时，把路径告诉 AI 即可。

## 资料空间

左侧「资料空间」列出当前项目的所有文件：

- 按类型（文档、图片、视频、音频）和分类（简介与品牌、知识库、素材、内容稿件）筛选，支持搜索、收藏、网格或列表视图。
- 点开可预览 Markdown、图片、视频；可以「交给 AI 处理」，或用默认应用打开、在文件夹中显示。
- 「创建」可以直接让 AI 写文档、生成图片或整理项目记忆。
